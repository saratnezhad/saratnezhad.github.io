# saratnezhad.github.io

Portfolio of Sara Taleb-Nezhad. Plain HTML and CSS, no build step.

## Files
- `index.html` home · `work.html` all projects · `work/klingele.html` case study · `about.html` · `contact.html` · `resume.html`
- `impressum.html`, `datenschutz.html`: fill in your address before going public
- `css/style.css`: all colours, fonts and spacing live in the `:root` block at the top
- `images/`: put project screenshots here, then change the `src` in the HTML
- `cv/`: add `cv-en.pdf` and `cv-de.pdf`

## Editing
1. Open a file in VS Code, change the text, save.
2. Double-click the file to preview it in your browser.
3. In GitHub Desktop: write a short summary, Commit to main, Push origin. The live site updates in about a minute.

## Adding a case study
Copy `work/klingele.html`, rename it (e.g. `work/thesis.html`), replace the content, then add a card for it in `work.html` and `index.html`.

## Placeholders
Grey boxes with [brackets] are image slots. Text in [brackets] is a fact only you have.
Add `images/og-image.png` (1200×630) so links preview nicely on LinkedIn.
